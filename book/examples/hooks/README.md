# Примеры хуков Qwen Code

Эти файлы относятся к части 17 учебника.

- `settings-workflow.example.json` — пример подключения трёх хуков.
- `pre_tool_guard.py` — блокирует несколько очевидно опасных команд перед запуском `Bash`.
- `log_tool_result.py` — пишет компактный журнал событий инструментов в `.qwen/hooks/logs/tool-events.jsonl`.
- `inject_sdd_context.py` — добавляет короткую памятку о SDD-файлах проекта.

Скопируйте скрипты в `.qwen/hooks/`, сделайте их исполняемыми и вручную объедините пример настроек с вашим `.qwen/settings.json`.
