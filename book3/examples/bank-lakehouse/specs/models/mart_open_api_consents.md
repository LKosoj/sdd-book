# Спецификация модели: mart_open_api_consents

## Назначение

Собрать синтетическое состояние согласий Open API по `scope`.

## Grain

Одна строка на `scope`.

## Входы

- `stg_open_api_consents`

## Семантика согласий

Пустой `revoked_at` в raw превращается в `null` в staging. В mart-слое
`revoked_at is null` означает активное согласие.

## Политика PII

В mart нет прямых PII-полей. Детализация согласий до уровня клиента находится вне
границ этой агрегированной витрины.

## Приёмочные факты

- `scope` не пустой.
- `consent_count`, `active_consent_count` и `revoked_consent_count` не пустые.
- Сумма счётчиков активных и отозванных согласий равна общему счётчику согласий.
- Первая и последняя даты выдачи согласия выводятся из `granted_at`.
