# Schema Manifest: cbr_rates

## Источник

- Файл: `raw/cbr_rates.csv`
- Роль системы: синтетическая выгрузка публичных справочных курсов
- Наблюдаемый grain: одна строка на `rate_date`, `currency`

## Наблюдаемые поля

| Поле | Наблюдаемый тип | Примечания |
|---|---|---|
| `rate_date` | date-like string | Дата курса. |
| `currency` | string | Код валюты. |
| `rate_rub` | decimal-like number | Курс к рублю. |

## Кандидаты ключей

- (`rate_date`, `currency`) — кандидат в составной ключ.

## PII-кандидаты

PII не наблюдаются.

## Заметки о качестве

- `rate_rub` должен быть положительным.
- Пропущенные даты требуют календаря боевого контура или политики заполнения, а не догадки
  агента.

## Открытые вопросы

- Какой источник является авторитетным в боевом контуре?
- Курс используется только для отчётности или для клиентских расчётов?
