# Технический стек

- Qwen Code CLI как агент-инструмент.
- dbt-core и dbt-duckdb для локального учебного трека.
- DuckDB как локальный аналитический движок.
- CSV/Parquet как имитация хранилища объектов.
- Стандартная библиотека Python для генерации синтетических источников.

Заметки о боевом контуре в книге могут показывать перенос на Iceberg/Trino/Databricks, но запускаемый трек не зависит от внешнего кластера.
